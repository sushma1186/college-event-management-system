# Event Management System

## Overview

The Event Management System is a web-based application developed to simplify and automate the process of managing events. The system allows students to view and register for events, while administrators can create, manage, and monitor events efficiently.

## Features

### Student Module

* User Registration and Login
* View Available Events
* Register for Events
* View Registered Events
* Free and Paid Event Registration

### Admin Module

* Admin Login
* Add New Events
* Delete Events
* View Event-wise Registered Students

## Technologies Used

### Frontend

* HTML
* CSS
* Bootstrap
* Thymeleaf

### Backend

* Java
* Spring Boot
* Spring MVC
* Spring Data JPA

### Database

* MySQL

## Project Architecture

The project follows the MVC (Model-View-Controller) architecture for better organization and scalability.
